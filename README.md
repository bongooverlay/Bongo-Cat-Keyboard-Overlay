## Getting Started
1. Get the zip above.
2. Extract and run `BongoCat.exe` (Mac: `.dmg`).
3. OBS: add the plugin, or Window Capture + Color Key `#FF00FF`.
4. Right-click the cat to swap skins.
5. Notes in `files/notes/`.

  <img width="1280" height="720" alt="images6" src="https://github.com/user-attachments/assets/cd4eb7d5-1a6f-49c7-a09b-6f0c98a4f02b" />

## Custom skins
Drop a pack into `skins/` next to the exe. Each pack is a JSON config plus PNG frames (idle, left, right, both).

## FAQ

**Bongo cat steam - is this the Steam game?**
Steam sells the paid original. This zip is the open overlay with the same bongo cat game look.

**bongo cat download / bongo cat download pc?**
Use the zip on this release. Portable, no installer.

**Does it work with an auto clicker?**
Yes. Global input means fast clicks become fast slaps.

**Mac?**
Intel and Apple Silicon `.dmg`, same features as Windows.

## Requirements
